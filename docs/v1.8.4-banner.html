Database Scaling Engine
Phase 1

Split connection pools, partitioned rollup tables, materialized catalog cache, and doubled PostgreSQL resources. The foundation for horizontal scaling.

🔀
Pool Isolation
API pool (35 conn) and Worker pool (15 conn) are fully separated. Workers can never starve user queries again.
📊
Partitioned Rollups
metric_rollup_5m and 1h are now monthly-partitioned. INSERT conflict checks hit one month, not 90 days.
⚡
Catalog Cache
Events catalog is pre-computed every 5 min. Response drops from ~500ms to <5ms. Zero GROUP BY scans on reads.
🐘
PG Resources 2x
Container doubled to 1 GB. shared_buffers 384 MB, work_mem 8 MB, effective_cache_size 768 MB. Better hit ratio.
